# Го (Go / Weiqi)

Премиальный мини-апп Telegram: древняя игра Го (вэйци) на доске 9x9, на русском.
Своя реализация без заимствований. Та же тёплая, уютная дизайн-система, что и у
соседних игр семейства.

Ставь камни на пересечения, окружай группы соперника и забирай их в плен,
обводи камнями пустоту и превращай её в свою территорию. В конце считаем по
площади с учётом коми. Правила учатся за минуту, а глубина бесконечная.

## Возможности

- Полный движок Го: группы и дыхания, взятие пленных, запрет самоубийства,
  правило ко, подсчёт по площади (китайский) с коми и картой территории.
- Боты трёх уровней: Новичок, Знаток, Мастер (своя эвристика, доигрывают партию
  и пасуют, когда полезных ходов нет, чтобы счёт был честным).
- Три режима: одиночная игра с ботом, быстрый онлайн-подбор (пустое место
  занимает бот под видом игрока) и игра с другом по коду из четырёх символов.
- Сервер авторитетен: доска, очередь, легальность хода, снятие пленных и счёт
  считаются на сервере. Клиент опрашивает состояние и отрисовывает доску.
- Пас и сдача, живой таймер хода, анимация постановки и снятия камней,
  синтезированные звуки, тактильная отдача, рейтинг и мягкая валюта.

## Архитектура

Монорепозиторий с воркспейсами npm:

- `shared/` общий код клиента и сервера: движок (`engine.ts`), боты (`bots.ts`),
  уровни сложности, ГСЧ, DTO. Покрыт юнит-тестами.
- `server/` Hono + better-sqlite3 + grammy. Авторизация Telegram (HMAC initData),
  сессионные JWT, менеджер комнат, бот с командами, раздача SPA.
- `app/` React + Vite + zustand. Дизайн-система в `app/src/theme.css`,
  доска-гобан в `app/src/game/Board.tsx`.

## Локальный запуск

```bash
npm install
npm run dev:server   # сервер на :3000 (DEV MODE без BOT_TOKEN)
npm run dev:app      # Vite на :5178, проксирует /api на сервер
```

Без `BOT_TOKEN` сервер стартует в DEV MODE и подменяет авторизацию одним
локальным игроком, удобно для разработки.

## Тесты и сборка

```bash
npm test         # движок, боты, менеджер комнат
npm run typecheck
npm run build     # собирает app/dist, который раздаёт сервер
```

## Деплой (Railway)

Railway собирает по `railway.json` (`npm install && npm run build`) и запускает
`NODE_ENV=production npm start`. Node закреплён на 22 (`.nvmrc`, `engines`), чтобы
better-sqlite3 ставил готовый бинарник.

Переменные окружения (см. `.env.example`):

- `BOT_TOKEN` из @BotFather. Без него вход через Telegram закрыт (401).
- `JWT_SECRET` длинная случайная строка. Обязателен в продакшене.
- `WEBHOOK_SECRET` случайная строка для пути вебхука.
- `BOT_USERNAME` имя бота без `@` (для диплинков в комнату).
- `APP_URL` публичный https адрес от Railway (для вебхука и кнопки Mini App).
- `DATA_DIR` путь к тому для SQLite, например `/data`.

После деплоя сервер сам регистрирует вебхук Telegram по `APP_URL`.
